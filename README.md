# 铁路信号联锁测试用例编排与回归记录平台

源提示词编号：14。包含道岔、信号机、轨道区段与进路关系，Canvas 站场缩放与定位，受设备变化影响的回归范围推导，用例步骤/预期/依赖编排，实时执行同步、断线重试、失败证据、基线锁定和测试报告导出。

## 交接班与发布门禁

针对白班/夜班接力跑同一用例、断网补传时旧执行号覆盖新进度的问题，平台用同一份交接记录把用例步骤、执行记录和发布基线串起来：

- **交接单**：交班时未完成步骤先挂起，全部凭证置为已交班；接班人接手后发放新执行号凭证、恢复挂起步骤。原执行人未交班且持有凭证未过期时不能续跑（也可模拟凭证过期后接手）。
- **执行凭证（一步一证）**：每步记录当前执行号、持证人、签发与过期时间、交班状态。
- **请求号幂等**：每份上报带 `requestId`，同一请求号重复上报只收一次，重复请求标记拒收。
- **晚到旧结果留作复核**：挂起、无凭证、已交班、凭证过期或执行号不符的上报不覆盖进度，进入「未决复核」队列，可采纳归档（不覆盖进度）或驳回。
- **依赖失效**：上游依赖步骤结果改动后，下游结果立即作废，原证据完整移入历史证据保留。
- **发布门禁**：逐步核验执行号、交接人、未决复核项，以及挂起、失效、缺记录、证据不一致等情形；任一不闭环即不予放行。
